# Crack & Carry

Crack & Carry — это многопользовательский платформер, разработанный с использованием Photon Engine и Proton (pun2). Игроки создают комнаты, подключаются к лобби.

## Возможности

- **Сетевая игра**: поддержка многопользовательского режима с хостом и клиентами через Photon Engine;
- **Динамичный геймплей**: стрельба от первого лица, взаимодействие с объектами, система очков;
- **Гибкость хоста**: хост управляет созданием комнаты, запуском игры и взаимодействует наравне с клиентами;
- **Простые правила**: для победы достаточно двух попаданий по противнику, после чего игроку начисляются очки.

## Технологии

- **Игровой движок**: Unity;
- **Сетевое взаимодействие**: Photon Engine (PUN2);
- **Язык программирования**: C#.

## Установка и запуск

1. Клонировать репозиторий:
   ```sh
   git clone https://github.com/твоя-ссылка-на-репозиторий.git
   ```
2. Открыть проект в Unity;
3. Настроить Photon (указать App ID в настройках);
4. Запустить сцену с лобби и начать игру!
